# ApnaLoan demo website

A static, mobile-friendly bilingual (English/Urdu) GitHub Pages starter site.

## Included
- `index.html` — homepage and five-step interactive demo
- `style.css` — responsive styling
- `app.js` — wizard navigation, validation, language toggle and on-screen summary

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish on GitHub Pages
1. Create a GitHub repository (for example, `ApnaLoan`).
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Important launch limitations
This is a demonstration only. It does not issue loans, assess eligibility, approve applicants, send leads to lenders, or collect real applications. Demo answers are only held in page memory and are not sent to a server or saved to a database.

Before collecting real applicant data or offering loans, obtain Pakistan-specific legal advice, confirm the required SECP/regulatory permissions and authorized lending arrangements, and implement secure backend infrastructure, privacy notices, consent, data retention/deletion controls and security testing.

Adsterra ad placements are intentionally not embedded. Add ads only after the site is approved by the ad network and ensure ads are clearly separate from form controls. Never encourage accidental clicks, forced ad views, or artificial page visits.
